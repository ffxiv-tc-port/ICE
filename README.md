# ICE（Ice's Cosmic Exploration）

[Ices-Cosmic-Exploration](https://github.com/LeontopodiumNivale14/Ices-Cosmic-Exploration) 的台服移植版，宇宙探索（Cosmic Exploration）自動化插件：自動接取/重擲任務、自動採集、自動製作、驛站活動與職業/月面自動切換。

## 功能

- **任務自動化**：自動確認或重擲（宇宙好運道）宇宙探索任務；提供「標準」模式（依優先度自動接取）與「達成度」模式（追蹤各任務金牌完成進度，方便收集稱號）
- **任務優先順序**：依職業、獎勵、經驗需求等條件自訂任務接取優先度
- **自動採集**：整合 [vnavmesh](https://github.com/awgil/ffxiv_navmesh) 自動導航採集，支援可自訂路線
- **自動釣魚**：整合 [AutoHook](https://github.com/InitialDet/AutoHook) 自動釣魚並接取收藏品任務
- **自動製作**：整合 [Artisan](https://github.com/PunishXIV/Artisan) 自動完成宇宙探索製作任務
- **月面/職業自動選擇**：自動切換塵寰海與昇天島，並依需求自動切換生產/採集職業
- **驛站活動**：自動兌換研究站商店物品，並可設定宇宙好運道自動重擲條件
- **機甲行動輔助**：在機甲事件中顯示技能範圍提示與報名開啟通知，純顯示不代操——不施放技能、不自動走位、不自動報名
- **停止條件與安全設定**：可設定達成目標後自動停止，以及各項安全防護選項

部分功能依需求選用 Artisan、AutoHook、vnavmesh，插件內建安裝按鈕可一鍵取得。
