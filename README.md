# ICE（Ice's Cosmic Exploration）

[Ices-Cosmic-Exploration](https://github.com/LeontopodiumNivale14/Ices-Cosmic-Exploration) 的台服移植版，宇宙探索自動化插件：自動接取與回報任務、自動採集、釣魚與製作、宇宙信用點數購物與宇宙好運道，並提供疊加層與機甲行動的資訊顯示。

任務自動化只在你按下主視窗或疊加層的「開始」、輸入 `/ice start`（或別的插件透過 IPC 呼叫）之後才會動，載入插件、登入或進入宇宙探索區域都不會自己開始；按「停止」、輸入 `/ice stop`、離開宇宙探索區域或達到停止條件就收手。有兩項不受開始／停止影響：「自動使用宇宙衝刺」（預設開啟，在宇宙探索區域內用製作／採集職業移動時自動施放，參與機甲行動時不放）與「啟用自動轉盤」（預設關閉，開著時打開宇宙好運道視窗就會自己開始轉）。

## 功能

- **任務自動化**：開始之後自動接取、執行、回報宇宙探索任務，挑不到想要的任務時放棄重骰（可設連續重骰上限）。有三種模式：「標準模式」（依你勾選的任務與優先順序）、「宇宙工具」（挑最能推進宇宙工具經驗值的任務）、「限定任務」（專接時間限定、天氣限定與連續任務）
- **任務優先順序**：可設定階級與職業的挑選順序、沒金星的優先、依表格排序挑任務、金星率過低的往後排；另有預設關閉的「條件差不多時優先接近的任務」，其他規則分不出先後時改接離你近的採集／釣魚任務
- **刷金星**：「取得金星後自動停用該任務」（預設關閉）開著時，拿到金星的任務不再接；連續任務要整串都拿到金星才會把前面的段落一起停用。限定任務模式另有「只刷勾選中未金星的任務」（預設關閉），勾選的都拿到金星就停止；連續幾次沒拿到金星的任務會先排到最後
- **任務表**：除了獎勵與經驗值，還有金星率、平均耗時、每小時金星、每小時信用點四個效益欄，點欄位標題就能排序（樣本太少的淡色顯示）；要等星球建設到更後面階段才會開放的任務以灰字標出「尚未開放」
- **全職業研究進度**：一個視窗列出每個職業的宇宙工具階段與各研究項目進度，可以直接換到該職業（只有 ICE 停止時能換）。宇宙工具模式可選擇在本職業工具這一階滿了時，照職業優先度換下一個職業繼續（預設關閉）
- **自動採集**：搭配 [vnavmesh](https://github.com/ffxiv-tc-port/vnavmesh) 自動導航採集，採集路線與採集配置（技能、最低 GP、最少採集數量）可自訂
- **自動釣魚**：搭配 [AutoHook](https://github.com/ffxiv-tc-port/AutoHook) 完成釣魚任務，可用內建的釣魚設定，也能替任務指定你自己的 AutoHook 設定
- **自動製作**：搭配 [Artisan](https://github.com/ffxiv-tc-port/Artisan) 完成製作任務；已經不可能拿到金星時可以選擇只提示或收手不做（預設關閉＝照舊做完）
- **月球與職業自動選擇**：自動選擇月球，並依任務自動切換製作／採集職業；候選任務空了可以改成換下一個職業再試，而不是直接停止（預設關閉）
- **宇宙信用點數購物與宇宙好運道**：自動購買設定好的商店道具（預設關閉，可設定已學會就不買）；宇宙好運道可依權重自動轉（預設關閉），也能在設定頁手動跑一次
- **停止條件**：達到指定等級、探索成果、宇宙信用點數、月球信用點數、宇宙工具完成、本區普通任務全部金星，或做完目前任務時自動停止；停下時可播放提示音，也能請 [NotificationMaster](https://github.com/ffxiv-tc-port/NotificationMaster) 跳出 Windows 通知或閃爍工作列圖示（預設關閉）
- **雜項**：自動使用宇宙衝刺、自動解除「貢獻之星」（預設關閉）、任務內外騎乘坐騎、在 NPC 處修理或自行修理、緊急任務結束後先返回基地（預設開啟）、任務結束後執行你設定的指令
- **疊加層**：顯示目前任務與目標進度、正要領取的任務、評價與金星進度、宇宙工具經驗值、天氣預報與時間限定任務（預設關閉）
- **機甲行動資訊**：技能範圍、技能冷卻、proc 提示、事件狀態與進度、下次機甲事件時間、目標標示，以及報名開放時的聊天通知（預設關）。以上 **全部只有顯示**——不施放技能、不自動走位、不自動報名

部分功能依需求選用 Artisan、AutoHook、vnavmesh，插件內建安裝按鈕可一鍵從台服插件倉庫取得。

## 指令

- `/ice`（別名 `/icecosmic`）：開關主視窗；`/ice s` 開啟設定頁；`/ice help` 在聊天視窗列出指令
- `/ice start`／`/ice stop`：開始／停止自動執行
- `/ice add|remove|toggle|only <任務 ID…>`：啟用／停用／切換／只啟用指定任務；`/ice clear` 停用全部任務
- `/ice flag <任務 ID>`：在地圖上標出該任務的採集範圍

## 台服版的修改

- 介面繁體中文化（依台服官方譯名），必要插件頁的安裝按鈕改指向台服插件倉庫。
- 機甲行動資訊顯示（上面列的那些）為台服版新增，全部只讀不代操；參與機甲行動時也不會自動施放宇宙衝刺。
- 新增「全職業研究進度」視窗，以及宇宙工具這一階滿了就換下一個職業的選項。
- 新增限定任務的「只刷勾選中未金星的任務」；取得金星後自動停用會把連續任務整串一起算。
- 任務表新增四個效益欄與「尚未開放」標記；任務挑選新增「沒金星的優先」「依表格排序挑任務」「條件差不多時優先接近的任務」、可調整的階級順序與連續重骰上限。
- 疊加層加上任務目標進度、待領取任務、評價進度與任務類型標籤。
- 宇宙信用點數商店改從遊戲資料讀取，任務分數表補上台服的任務，效率排序不再失準。
- 角色還沒解鎖收藏品或精選時，在任務表與聊天視窗提醒要完成哪個支線任務。
- 製作任務開工前先下坐騎；製作失敗或拿不到金星的任務會先排到後面，不再反覆重接。
- 執行期間暫停 AutoRetainer；借用 AutoHook 開關與 vnavmesh 導航設定時，跑完或卸載後還原你的設定；ICE 自己停下來時只停自己的導航，不取消別的插件正在走的路。
- 搭配 TataruPraise：交件拿到金星時誇獎，自動化停下或卡住時請塔塔露說一聲；搭配 NotificationMaster：停下時跳出 Windows 通知。
- 巨集與其他插件可以透過 IPC 查到 ICE 停下來的原因（`ICE.StopReason`）；TCToolbox 的「全艦隊急停」會一併停下 ICE。
- 修正多處按遊戲視窗時重按正在關閉的視窗造成遊戲崩潰，以及任務被遊戲取消時的連鎖錯誤。
- 介面寬度跟著 Dalamud 的字型大小放大；多處降低記憶體用量。

## 安裝

1. 在遊戲內輸入 `/xlsettings` 開啟「Dalamud 設定」，到「試驗性功能」分頁的「第三方插件倉庫」（Custom Plugin Repositories）貼上
   `https://raw.githubusercontent.com/ffxiv-tc-port/DalamudPluginsTC/main/repo.json`
   勾選啟用後按「儲存變更」。
2. 輸入 `/xlplugins` 開啟「插件管理員」（Plugin Installer），搜尋「Ice's Cosmic Exploration」安裝。

請不要安裝上游（國際服）版本，它不是對著台服客戶端做的。
